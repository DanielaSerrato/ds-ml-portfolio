# Portfolio — Plan de Trabajo

## Objetivo
Construir un portafolio completo que refleje a Daniela como **profesional de datos integral** — no solo DS, sino BI (core), ML, AI, EdTech, y analisis de datos con contexto colombiano.

## Estructura del Portafolio

### Categorias de proyectos
1. **Analytics & BI** — dashboards ejecutivos, riesgo crediticio, logistica (datos ficticios inspirados en experiencia real)
2. **Data Science & ML** — 6 notebooks (segmentacion, churn, riesgo, forecasting, NLP, geospatial)
3. **AI in Production** — GoliA (ML + Streamlit), Agente WhatsApp (n8n + LLM)
4. **EdTech & Teaching** — Planta SQL, cursos universitarios, herramientas interactivas
5. **Analisis de Datos Colombia** (nuevo) — proyectos con datos publicos colombianos, util para formacion corporativa y MinDefensa
