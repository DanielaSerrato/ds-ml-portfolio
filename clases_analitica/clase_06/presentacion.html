1 Importar datos

Obtener datos → Desde CSV → Preview → Cargar

-- Pasos en Power BI Desktop:

1. Inicio → Obtener datos → Texto/CSV
2. Buscar el archivo DANE_mercado_laboral_GEIH.csv
3. Verificar la vista previa (delimitador, tipos)
4. Clic en Cargar o Transformar datos

Tip

Siempre revisen la vista previa antes de cargar. Verifiquen que las columnas se detectaron correctamente.

2 Power Query: limpiar datos

ETL: Extract → Transform → Load

Extract

Conectarse a la fuente de datos (CSV, Excel, SQL, API...)

Transform

Renombrar columnas, cambiar tipos, eliminar filas vacias, filtrar

Load

Enviar los datos limpios al modelo de Power BI

-- Operaciones comunes en Power Query:

Renombrar columnas → doble clic en encabezado
Cambiar tipo → clic en icono de tipo (ABC, 123, fecha)
Eliminar filas → Quitar filas en blanco
Cerrar y aplicar → Cerrar & Aplicar

3 Tabla de fechas: DimFecha

Por que necesitamos una tabla de fechas?

  • Inteligencia temporal: comparar trimestres, calcular YoY, filtrar por anio
  • Power BI necesita una tabla de fechas continua para funciones de tiempo (DAX)
  • Mejora la organizacion del modelo: separa hechos de dimensiones
-- Crear tabla DimFecha en Power Query o DAX:

Columnas sugeridas:
  fecha      (2023-01-01, 2023-04-01, ...)
  anio       (2023, 2024, 2025)
  trimestre  (Q1, Q2, Q3, Q4)
  anio_trim  (2023-Q1, 2024-Q2, ...)

Esquema estrella simplificado

Fact table + Dimension table

DimFecha
PK fecha
    anio
    trimestre
    anio_trim
⟷
FactEmpleo
FK fecha
    departamento
    tasa_desempleo
    tasa_ocupacion
    tasa_informalidad

Dimension = describe el contexto (cuando, donde)  |  Hecho = contiene las medidas (tasas, conteos)

4 Primer visual: grafico de barras

Tasa de desempleo por departamento

-- Pasos para crear el grafico:

1. Ir a la vista de Informe (icono de grafico)
2. En Visualizaciones → seleccionar Grafico de barras agrupadas
3. Arrastrar Departamento al eje Y
4. Arrastrar tasa_desempleo al eje X
5. Ordenar de mayor a menor (clic en “...” del visual)

Resultado: un ranking visual de desempleo por departamento.

Tipos de visuales en Power BI

Cuando usar cada uno?

🔢

Tarjeta (KPI)

Un numero clave: promedio, total, maximo

📊

Barras

Comparar categorias: departamentos, regiones

📈

Lineas

Tendencias en el tiempo: trimestres, anios

🗺️

Mapa

Datos geograficos: desempleo por region

📋

Tabla

Detalle exacto: todas las filas y columnas

Regla: el visual debe responder una pregunta especifica, no decorar.

Slicers y filtros: interactividad

Hacer el dashboard dinamico

Slicer de Anio

Permite al usuario filtrar por 2023, 2024 o 2025. Todos los visuales se actualizan al seleccionar.

Slicer de Departamento

Lista desplegable o botones para elegir uno o varios departamentos. Ideal para comparar regiones.

-- Como agregar un slicer:

1. Visualizaciones → Segmentacion de datos
2. Arrastrar el campo (anio o departamento) al slicer
3. Formatear: estilo lista, desplegable o botones
4. Probar: clic en un valor y ver como cambian los graficos

Formato profesional

“Menos es mas”

Buenas practicas

  • Titulo descriptivo en cada visual
  • Etiquetas en los ejes (unidad: %)
  • Paleta de colores consistente
  • Maximo 4-5 visuales por pagina
  • Espacio en blanco = claridad

Errores comunes

  • Demasiados colores sin proposito
  • Graficos 3D (distorsionan datos)
  • Sin titulo ni etiquetas
  • Demasiados visuales en una pagina
  • Fuentes pequenas ilegibles

Un dashboard profesional comunica, no impresiona.
