# Clase 1 — Respuestas Docente

## Puntos clave para facilitar la discusión

### Dato vs Información vs Conocimiento
- **Respuesta esperada:** Dato = número crudo (32°C), Información = dato con contexto (Bogotá tuvo 32°C ayer), Conocimiento = información procesada + experiencia (temperatura inusual → posible cambio climático)
- **Por qué importa:** Los participantes tienden a confundir "tener datos" con "tener información". Aclarar esto temprano evita que piensen que tener un Excel = tener respuestas.
- **Trampa común:** "Yo ya tengo datos" — sí, pero ¿los has convertido en información?

### Tipos de datos
- **Numéricos:** Se pueden sumar, promediar, comparar. Ej: población, presupuesto, tasa.
- **Categóricos:** Agrupan. Ej: departamento, tipo de delito, género.
- **Fechas:** Permiten ver tendencias. Ej: año, trimestre, fecha de registro.
- **Texto:** Contexto cualitativo. Ej: observaciones, nombres, descripciones.
- **Trampa común:** Confundir códigos numéricos (ej: código DANE "05001") con datos numéricos. Si no tiene sentido sumar, no es numérico.

### Ejercicio 2 — Abrir CSV en Excel
**Problemas esperados:**
1. El CSV se abre mal → separador incorrecto (punto y coma vs coma)
2. Tildes rotas → codificación UTF-8 vs Latin-1
3. Números como texto → formato de celdas
4. No encuentran cuántas filas → Ctrl+End o mirar barra de estado

**Respuesta:** Si se abre mal, usar Datos → Obtener datos → Desde archivo CSV y elegir delimitador y codificación UTF-8.

### Discusión final
**Preguntas para provocar:**
- "¿Qué decisión tomaron esta semana basada en datos? ¿Y cuál fue por intuición?"
- "Si tuvieran un dashboard con estos datos actualizado cada mes, ¿qué harían diferente?"
- "¿Quién en su equipo se beneficiaría más de ver estos datos?"

**Lo que queremos lograr:** Que se den cuenta de que los datos ya existen, son públicos, y pueden cambiar la forma en que toman decisiones. No necesitan ser "técnicos" para usarlos.
