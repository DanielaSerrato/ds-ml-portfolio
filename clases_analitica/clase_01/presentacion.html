Datos Abiertos de Colombia

datos.gov.co — El portal de datos abiertos del Estado

  • Más de 30,000 datasets publicados
  • Entidades: DANE, MinSalud, MinEducación, Policía Nacional, DNP...
  • Temas: educación, salud, seguridad, economía, ambiente, transporte
  • Formatos: CSV, Excel, JSON, API
  • Gratuitos y de libre acceso — cualquiera puede descargarlos

¿Qué puedo encontrar?

📚 Educación

🔒 Seguridad

💰 Economía

Calidad del aire, deforestación, áreas protegidas

Ejercicio 1 — Explorar datos.gov.co

🔍 Instrucciones

  • Ir a datos.gov.co
  • Explorar el catálogo: ¿cuántos datasets hay? ¿Qué entidades publican?
  • Buscar 3 datasets relevantes para su área de trabajo
  • Para cada uno anotar: nombre, entidad, qué contiene, por qué es útil

⏱️ 15 minutos

De la web a Excel

Descargar un CSV y abrirlo

Paso 1: En datos.gov.co → elegir un dataset → clic en "Exportar"
Paso 2: Descargar como CSV
Paso 3: Abrir Excel → Datos → Obtener datos → Desde archivo CSV
Paso 4: Verificar: delimitador (coma o punto y coma), codificación UTF-8
Paso 5: Explorar: ¿cuántas filas? ¿cuántas columnas? ¿qué tipos de datos?

Ejercicio 2 — Mi primer análisis

📋 Instrucciones

  • Descargar uno de los 3 datasets que encontraron
  • Abrirlo en Excel
  • Identificar: ¿cuántas filas? ¿cuántas columnas?
  • Clasificar cada columna: numérica, categórica, fecha o texto
  • Encontrar un dato que les sorprenda
