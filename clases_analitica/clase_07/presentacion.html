Foreign Keys (llaves foraneas)

"La columna que conecta dos tablas"

📚 Concepto

Una columna en la tabla A que hace referencia a la misma columna en la tabla B

✅ En nuestro caso

municipio y departamento existen en ambas tablas: es el puente

⚠️ Cuidado

Los valores deben coincidir exactamente: mayusculas, tildes, espacios

Sin esta conexion, Power BI no sabe como cruzar la informacion.

Que es DAX?

Data Analysis eXpressions

Formulas de Power BI, como las de Excel pero mas poderosas.

📈 Excel

=SUMA(A1:A100)

Opera sobre celdas fijas

⚡ DAX

=SUM(tabla[columna])

Opera sobre toda la columna y respeta filtros automaticamente

DAX se adapta al contexto: si filtras por departamento, recalcula solo ese departamento.

Medida 1: Total Delitos

Nuestra primera medida DAX

// Click derecho en la tabla delitos → Nueva medida

Total Delitos = SUM( delitos[cantidad] )
  • SUM — suma todos los valores de la columna cantidad
  • Se adapta al contexto: si hay un filtro por municipio, solo suma ese municipio
  • Arrastrar la medida a una tarjeta para ver el total general

Medida 2: Tasa por 100K

Delitos relativos a la poblacion

Tasa por 100K =
    DIVIDE(
        [Total Delitos],
        SUM( poblacion[poblacion] )
    ) * 100000
  • DIVIDE — division segura (no da error si el denominador es 0)
  • Usa la relacion para traer la poblacion correcta de cada municipio
  • Multiplicamos por 100.000 para obtener una tasa comparable

Medida 3: Variacion Anual

Comparar con el anio anterior

Delitos Anio Anterior =
    CALCULATE(
        [Total Delitos],
        FILTER(
            delitos,
            delitos[anio] = MAX(delitos[anio]) - 1
        )
    )

Variacion % =
    DIVIDE(
        [Total Delitos] - [Delitos Anio Anterior],
        [Delitos Anio Anterior]
    )

CALCULATE cambia el contexto de filtro: evalua la misma formula pero en un periodo diferente.

Medidas vs Columnas calculadas

Cuando usar cada una?

📊 Medidas (Measures)

  • Se calculan al momento de usar el visual
  • Se adaptan a los filtros
  • Ideales para agregaciones: SUM, AVERAGE, COUNT
  • No agregan columnas a la tabla

📋 Columnas calculadas

  • Se calculan una vez al refrescar datos
  • Crean una nueva columna fija
  • Ideales para valores por fila: categorias, concatenaciones
  • Ocupan espacio en el modelo

Regla general: si necesitas agregar (sumar, promediar) → medida. Si necesitas un valor por cada fila → columna calculada.

Construyendo el dashboard

2 paginas, 2 perspectivas

Pagina 1: Panorama Nacional

🌎 Mapa

Delitos por departamento (burbujas o color)

📊 KPIs

Total Delitos, Tasa x 100K, Variacion %

📈 Linea de tendencia

Evolucion mensual de delitos (eje X = mes, Y = cantidad)

Pagina 2: Detalle por Delito

📊 Barras

Top 10 municipios por tipo de delito

🔎 Filtros

Segmentadores: delito, anio, departamento

📋 Tabla detalle

Tabla con drill-down: depto → municipio → delito

Drill-down y Drill-through

Navegar desde lo general al detalle

🔍 Drill-down

Dentro del mismo visual:

Departamento → Municipio → Tipo de delito

Agregar varios campos al eje del grafico. Usar las flechas de navegacion.

📄 Drill-through

Navegar a otra pagina:

Click derecho en un departamento → "Obtener detalles" → pagina de detalle

Configurar campo de drill-through en la pagina destino.

El drill-down explora dentro del visual. El drill-through salta a otra pagina con contexto.
