Porque los datos reales nunca vienen listos para analizar

Los datos reales NUNCA vienen limpios

Celdas combinadas

Excel no puede filtrar ni calcular sobre celdas fusionadas

Filas vacías

Separadores visuales que rompen los rangos de datos

Nombres inconsistentes

"BOGOTA", "Bogotá", "BOGOTA D.C." — el mismo lugar, tres formas

Tipos mezclados

Una columna de población con números y textos como "N/D" o "-"

Si no limpiamos, el análisis será incorrecto — basura entra, basura sale.

🏛️

El dataset del DANE

Proyecciones de población por departamento

  • ¿Qué es? Estimaciones de población del DANE por municipio, departamento y año
  • ¿Dónde encontrarlo? dane.gov.co → Estadísticas por tema → Demografía y Población → Proyecciones de población
  • ¿Por qué este dataset? Es público, real, y tiene los problemas típicos de datos gubernamentales
  • Formato: Archivo Excel (.xlsx) con múltiples hojas y formatos complejos

Problemas típicos en datos del gobierno

Celdas combinadas

Encabezados que abarcan varias columnas para "verse bonito"

Múltiples filas de encabezado

Títulos, subtítulos y notas antes de los datos reales

Filas vacías como separadores

Espacios en blanco entre secciones que rompen el análisis

Nombres con variaciones

"Nariño" vs "NARIÑO" vs "NARINO" — tildes y mayúsculas inconsistentes

Números como texto

Población guardada como texto con puntos de miles: "1.234.567"

Notas al pie dentro de los datos

Asteriscos, referencias y fuentes mezclados con las cifras

Paso a paso: abrir e identificar problemas

Paso 1: Abrir el archivo original — NO modificar nada todavía
Paso 2: Observar las primeras filas — ¿dónde empiezan los datos reales?
Paso 3: Revisar si hay celdas combinadas (Inicio → Combinar y centrar)
Paso 4: Buscar filas vacías — Ctrl+End para ver dónde termina el rango
Paso 5: Revisar tipos — ¿los números están alineados a la derecha?
Paso 6: Anotar todos los problemas antes de empezar a limpiar

Regla de oro: primero diagnosticar, después limpiar.

Ejercicio 1 — Identificar problemas

🔍 Instrucciones

  • Abrir el archivo de proyecciones de población del DANE
  • Recorrer las primeras 20 filas — ¿qué ven?
  • Listar al menos 5 problemas que encuentren
  • Para cada problema escribir: fila/columna donde está y por qué es un problema
  • Compartir con su compañero de al lado

⏱️ 15 minutos

Técnica 1: Deshacer celdas combinadas y fijar encabezados

1. Seleccionar todo: Ctrl + E
2. Inicio → Combinar y centrar → Separar celdas
3. Eliminar filas de título que no son datos (clic derecho → Eliminar fila)
4. La primera fila debe ser los nombres de las columnas
5. Renombrar columnas con nombres claros y sin espacios innecesarios
6. Un encabezado por columna, una fila de encabezados

Siempre trabajar en una copia del archivo original. Nunca modificar la fuente.

Técnica 2: Eliminar filas vacías y corregir tipos

Filas vacías:
  Seleccionar rango → Ctrl+G → Especial → Celdas en blanco
  Clic derecho → Eliminar fila completa

Tipos de datos:
  Seleccionar columna de población
  Datos → Texto en columnas → Delimitado → Finalizar
  Formato de celda → Número (sin decimales)

Si ven un triángulo verde en la esquina de la celda, Excel detectó un número guardado como texto.

Técnica 3: Nombres consistentes

Departamentos con tildes y mayúsculas uniformes

Problema: "BOGOTA" ≠ "Bogotá" ≠ "BOGOTA D.C."

Solución con fórmulas:
  =MAYUSC.INICIAL(A2) → convierte a "Bogotá"
  =SUSTITUIR(A2,"BOGOTA D.C.","Bogotá D.C.")

Buscar y reemplazar:
  Ctrl+H → Buscar "NARINO" → Reemplazar con "Nariño"
  Repetir para cada variación encontrada

Clave: un mismo lugar debe tener siempre el mismo nombre exacto.

Ejercicio 2 — Limpiar el dataset

🛠️ Instrucciones

  • Crear una copia del archivo original
  • Deshacer todas las celdas combinadas
  • Eliminar filas de título y notas — dejar solo datos
  • Fijar los encabezados en la primera fila
  • Eliminar filas vacías
  • Corregir nombres de departamentos (tildes, mayúsculas)
  • Verificar que la columna de población sea numérica

Filtros en Excel

Explorar la tabla limpia

Activar filtros:
  Seleccionar la tabla → Datos → Filtro (o Ctrl+Shift+L)

Filtrar por departamento:
  Clic en la flecha de "Departamento" → Seleccionar solo "Antioquia"

Filtrar por año:
  Clic en la flecha de "Año" → Seleccionar solo "2025"

Ordenar:
  Clic en la flecha de "Población" → Ordenar de mayor a menor

Los filtros solo funcionan bien sobre tablas limpias y planas.
