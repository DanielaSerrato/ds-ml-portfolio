Sales Forecasting.

Pronostico de Ventas.

Overview.
Descripcion General.

Retail businesses make inventory and budget decisions months in advance. Overstock ties up capital; understock means lost sales. Accurate demand forecasting is the bridge between operational planning and financial reality.

Los negocios de retail toman decisiones de inventario y presupuesto con meses de anticipacion. El sobrestock inmoviliza capital; el substock significa ventas perdidas. El pronostico preciso de demanda es el puente entre la planeacion operativa y la realidad financiera.

This project builds a 3-month sales forecast using two complementary approaches: statistical time series models (ARIMA/SARIMA with systematic grid search) and machine learning (Random Forest with engineered lag features). Both are evaluated on a 12-week holdout to ensure the forecast generalizes to unseen periods.

Este proyecto construye un pronostico de ventas a 3 meses usando dos enfoques complementarios: modelos estadisticos de series de tiempo (ARIMA/SARIMA con busqueda sistematica de parametros) y machine learning (Random Forest con variables de rezago ingenierizadas). Ambos se evaluan en un holdout de 12 semanas para asegurar que el pronostico generalice a periodos no vistos.

The comparison matters: SARIMA captures seasonality explicitly, while Random Forest can learn non-linear demand patterns. Understanding when each excels guides production model selection.

La comparacion importa: SARIMA captura estacionalidad explicitamente, mientras Random Forest puede aprender patrones de demanda no lineales. Entender cuando cada uno sobresale guia la seleccion del modelo en produccion.

Approach.
Metodologia.
  1. Time Series EDA: Decomposed series into trend, seasonality, and residual components. Tested stationarity with ADF test. Analyzed ACF/PACF for parameter hints.
  2. EDA de Series de Tiempo: Descompuse la serie en componentes de tendencia, estacionalidad y residuos. Probe estacionariedad con test ADF. Analice ACF/PACF para pistas de parametros.
  3. ARIMA/SARIMA Grid Search: Systematic search over (p,d,q) and seasonal (P,D,Q,s) parameters. Ranked by AIC/BIC. Best model: SARIMA with weekly seasonality.
  4. Busqueda de Parametros ARIMA/SARIMA: Busqueda sistematica sobre parametros (p,d,q) y estacionales (P,D,Q,s). Rankeados por AIC/BIC. Mejor modelo: SARIMA con estacionalidad semanal.
  5. ML Feature Engineering: Created lag features (1, 7, 14, 28 days), rolling means/std (7, 14, 30 windows), day-of-week, month, and holiday indicators for Random Forest.
  6. Ingenieria de Variables ML: Cree variables de rezago (1, 7, 14, 28 dias), medias/std moviles (ventanas 7, 14, 30), dia de semana, mes e indicadores de festivos para Random Forest.
  7. Model Evaluation: Both models evaluated on 12-week holdout. Metrics: MAPE, RMSE, MAE. Full residual diagnostics (normality, autocorrelation, heteroscedasticity).
  8. Evaluacion de Modelos: Ambos modelos evaluados en holdout de 12 semanas. Metricas: MAPE, RMSE, MAE. Diagnostico completo de residuos (normalidad, autocorrelacion, heterocedasticidad).
  9. Forecast & Comparison: Generated 3-month forward forecasts from both models. RF matched SARIMA accuracy, offering a non-parametric alternative for production deployment.
  10. Pronostico y Comparacion: Genere pronosticos a 3 meses de ambos modelos. RF igualo la precision de SARIMA, ofreciendo una alternativa no parametrica para despliegue en produccion.
